Test assistant

Sends one minimal, real request to OpenAI to verify the active key and measure latency. This is billed work — it costs a fraction of a cent per click.

Rotate OpenAI key

Paste the new secret key from the OpenAI dashboard. It is validated against the OpenAI API before being stored and is never displayed, logged or kept anywhere by this page.

On success it becomes the only enabled Secret Manager version — prior versions are disabled immediately and running instances switch within ~5 minutes. The field is cleared after every attempt.
